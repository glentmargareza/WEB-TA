# AI PROJECT INSTRUCTIONS

## 1. Aturan Utama
- Pahami struktur project yang sudah ada sebelum mengubah kode.
- Jangan mengubah konsep, tujuan, atau desain utama project tanpa persetujuan.
- Jangan membuat fitur baru di luar permintaan.
- Jangan menghapus atau mengganti kode yang masih berfungsi tanpa alasan jelas.

## 2. Aturan Coding
- Ikuti bahasa pemrograman, framework, dan pola coding yang sudah digunakan.
- Gunakan kembali komponen, fungsi, dan file yang tersedia jika memungkinkan.
- Hindari membuat file duplikat atau kode yang tidak diperlukan.
- Pastikan perubahan tidak merusak fitur lain.

## 3. Sebelum Mengubah Kode
- Periksa file yang berkaitan dengan permintaan.
- Jelaskan rencana perubahan secara singkat.
- Jika instruksi tidak jelas, tanyakan terlebih dahulu.
- Jangan langsung merombak seluruh project.

## 4. Setelah Mengubah Kode
- Jelaskan file yang diubah dan alasannya.
- Periksa kemungkinan error dan dampak terhadap fitur lain.
- Jangan mengubah konfigurasi penting atau file .env tanpa izin.

## 5. Batasan Project
- Fokus hanya pada project WEB-TA.
- Pertahankan struktur folder dan database yang sudah ada.
- Jangan mengubah fitur di luar ruang lingkup tugas.
- Utamakan perubahan kecil, aman, dan sesuai permintaan pengguna.
