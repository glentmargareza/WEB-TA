## Database Project

- Sebelum membuat fitur yang berhubungan dengan database, baca `docs/database.md`.
- Gunakan nama tabel, kolom, dan relasi sesuai dokumentasi.
- Periksa migration dan kode yang sudah ada sebelum mengubah database.
- Jangan menghapus, mereset, atau mengubah struktur database tanpa persetujuan.
- Jika ada perbedaan antara dokumentasi dan database aktual, laporkan terlebih dahulu sebelum melakukan perubahan.
